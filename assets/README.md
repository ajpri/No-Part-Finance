# PWA icon placeholders

Icon artwork is pending. No placeholder images are served by the application.

Supply a square SVG or a high-quality 1024 × 1024 PNG source. Planned exports:

- `icon-192.png`: 192 × 192 standard icon.
- `icon-512.png`: 512 × 512 standard icon.
- `icon-maskable-512.png`: 512 × 512 maskable icon with an opaque background and essential artwork inside the centered 80%-diameter safe circle.
- `apple-touch-icon.png`: 180 × 180 iPhone/iPad home-screen icon.

Do not bake rounded corners into the source artwork.
